##Балансировка и отказоустойчивости с использованием Nginx

###Реализовано приложение, по обращению к endpoint которому увеличивается счетчик counter
###С помощью конфигурационных файлов nginx реализованы алгоритмы балансировки round robin, random и weight
###Результаты нагрузочного тестирования были выполнены с помощью программы Apache benchmark
